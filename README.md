# PelotonSync · web del proyecto

Sitio estático (HTML, CSS y JS) con el manual de marca, la investigación, el wireframe y el prototipo de PelotonSync.

- `src/`: contenido de cada página. `python3 build.py` arma las páginas con el menú y el pie.
- `assets/`: pantallas, ilustraciones y estados de Grega exportados de Figma.
- 3D con three.js desde CDN.

Proyecto de práctica en el entorno de SAHG SAS y Higuita Monster.
